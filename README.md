# Homebrew Midfleet

Homebrew tap for the Midfleet CLI.

```bash
brew tap Midfleet/midfleet
brew install midfleet
```

The formula is updated by the Midfleet `publish-agent.yml` GitHub Actions workflow when an `agent-v<version>` tag is published.

## About Midfleet

Midfleet is the coordination, orchestration, and governance runtime for autonomous AI work. Midfleet was co-founded and is being built by [Ahmed Mashadani](https://github.com/ahmashadani) and [Raju Shahi](https://github.com/therajushahi).
